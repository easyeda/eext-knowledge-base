使用说明
  1. 分别设置 Chat 和 Embedding 的 API 开关，AI问答会自动使用所选组合。
  2. 关闭 API 后，可选择镜像站下载或导入完整的 Transformers.js ONNX 模型文件夹。
  3. 导入后点击“使用”选择对应本地模型；开启 API 时保留本地选择。
  4. 插件仅包含文档文本。首次使用请在助手中点击“开始构建”，使用当前 Embedding 模型为全部有效文档构建向量；之后自动复用该模型的本地缓存。
