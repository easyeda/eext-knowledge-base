# 学生如何提交作业

1. 进入嘉立创EDA编辑器（以专业版为案例，标准版进入学校页面步骤一样）

<center>
<img src="/storage/images/zh-hans/design-production/education/submit-job/submit-job_20241121_100239.png" width="1000">
</center>

2. 在左上角的工作区选择已加入的学校

<center>
<img src="/storage/images/zh-hans/design-production/education/submit-job/submit-job_20241121_100353.png" width="600">
</center>

3. 进入班级，选择老师规定的作业提交文件夹，在指定的文件夹中新建工程

<center>
<img src="/storage/images/zh-hans/design-production/education/submit-job/submit-job_20241121_100540.png" width="1000">
</center>

4. 填写好相关信息，点击保存

<center>
<img src="/storage/images/zh-hans/design-production/education/submit-job/submit-job_20241121_100827.png" width="1000">
</center>

5. 在工程中完成对应作业的绘制，直接保存即可，后续老师可直接打开该工程进行查看与点评。

<center>
<img src="/storage/images/zh-hans/design-production/education/submit-job/submit-job_20241121_101311.png" width="1000">
</center>
