# 创建我的团队（创建班级）

1. 进入学校主页，点击“创建团队”

<center>
<img src="/storage/images/zh-hans/design-production/education/creating-team/creating-team_20241120_142732.png" width="800">
</center>

2. 依次填写信息

-   团队头像：可上传个性化头像，也可上传校徽
-   团队名称：可以是班级名称，也可以根据比赛等情况进行个性化编辑
-   团队链接：一般根据团队名称生成，若过长，可适当删减
-   团队简介：可以写此次团队组建的原因，或教学主题等，根据个人需求填写
-   添加成员：可添加组织内成员（也可创建好后再添加）

参考：

<center>
<img src="/storage/images/zh-hans/design-production/education/creating-team/creating-team_20241120_143206.png" width="800">
</center>

3. 点击创建
4. 创建成功会跳转到学校首页，页面中会显示创建的所有班级，点击已创建成功的班级即可进入，并布置作业、查看作业。
