# 线上考试

1. 班级创建者进入班级页面，选择考试目录

<center>
<img src="/storage/images/zh-hans/design-production/education/exam/exam_20241121_102418.png" width="1000">
</center>

2. 新建考试

<center>
<img src="/storage/images/zh-hans/design-production/education/exam/exam_20241121_103427.png" width="1000">
</center>

3. 创建完考试后，待启用时间一到，学生即可看到考试信息，老师可再次点击考试修改考试工程。待学生开始考试或考试完成后，可点击考试右侧选项按钮查看考卷或查看考试成绩单。

<center>
<img src="/storage/images/zh-hans/design-production/education/exam/exam_20241121_104225.png" width="1000">
</center>

4. 班级创建者/管理员可以对考试工程进行评分和查看，这与平时作业批改一致，待所有考卷批改完成后，即可一键查看成绩单。

<center>
<img src="/storage/images/zh-hans/design-production/education/exam/exam_20241121_104710.png" width="1000">
</center>
