# 前言

::: info 注意

目前教育工作区已上线考试功能！！！

:::

&emsp;&emsp; 嘉立创EDA有标准版、专业版两个版本，教育工作区是一个线上的教育系统（教育工作区又名教育版），在标准版、专业版中都支持教育工作区，老师可以在教育工作区中创建线上学校、线上班级，布置作业、线上评分、线上考试等功能。
<br/>

&emsp;&emsp;想要使用教育工作区，需要先向嘉立创EDA官方工作人员进行申请，通过后您可以创建自己的线上学校，学生使用自己的嘉立创EDA账号接收您的邀请之后进入该学校，后续您可以在该工作区中对学生进行统一管理。
<br/>

&emsp;&emsp;例如：可以在教育工作区中创建班级，同时创建一个文件夹，用于收集每一次的作业，您可以实时线上查看他们的进度，并且进行线上评分和点评。
